# Spotify User Engagement & Subscription Insights Dashboard

## Objective

Analyze Spotify user behavior, engagement patterns, subscription preferences, and advertisement conversion trends using Power BI.

## Tools Used

- Power BI
- Power Query
- DAX

## KPIs

- Total Users
- Average Listening Hours
- Average Music Rating

## Dashboard Features

- User segmentation by Age Group
- Country-level filtering
- Subscription type analysis
- Genre engagement analysis
- Ad interaction and conversion tracking
- Interactive dashboard experience

## Key Insights

- Free subscription plan represents the largest share of users.
- User engagement remains relatively consistent across subscription plans.
- Advertisement interactions influence subscription conversion behavior.
- Listening patterns can be analyzed across age groups and countries.

## Business Recommendations

- Improve premium subscription conversion campaigns.
- Personalize marketing strategies by demographic segment.
- Optimize ad targeting based on user engagement behavior.
- Focus retention efforts on highly engaged users.
